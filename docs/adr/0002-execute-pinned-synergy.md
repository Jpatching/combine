# Execute pinned Synergy rather than imitate its menu

The owner rejected the native Intervention menu presentation and selected actual
Synergy GSC, including its presentation and options. Execute the pinned source
through the existing script compiler, simulation and HUD; keep adaptations narrow
and traceable. A native imitation would change the requested behavior and require
maintaining another menu. Preserve the earlier patches for reproduction.

The containing crate keeps GPLv3 and attribution. Retail scripts and game assets
remain private. Integration checks and physical owner acceptance are separate.
The [menu contract](../TRICKSHOT_MENU.md) retains unresolved option and near-pass
requirements. This decision does not authorize a universal script loader.
