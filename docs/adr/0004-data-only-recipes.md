# Keep recipes as offline research data

The selected recipes describe two pinned candidates for manual investigation.
Validate them offline as strict data, without executable commands, paths or
download URLs. Combining validation with automatic installation or launch would
expand both authority and the handling of private game data.

The [recipe contract](../RECIPE.md) owns their fields. No automatic recipe
application or production launcher follows from a successful validation.
Source licences and local game ownership do not settle asset redistribution;
release needs separate rights evidence and owner authority.
